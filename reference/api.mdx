The ClawHQ dashboard exposes a REST API for managing agents, settings, and integrations programmatically.

## Base URL

```
http://localhost:3500/api
```

Replace `localhost:3500` with your ClawHQ domain in production.

## Authentication

All API requests require a valid session. Authenticate via WorkOS (see [dashboard login](/quickstart)) and include the session cookie, or generate an API token under **Settings → General → API Tokens**.

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://your-clawhq.com/api/agents
```

## Endpoints

### Agents

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/agents` | List all agents |
| `GET` | `/api/agents/:id` | Get agent details |
| `POST` | `/api/agents` | Create an agent |
| `PATCH` | `/api/agents/:id` | Update agent config |
| `DELETE` | `/api/agents/:id` | Delete an agent |

### Settings

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/settings` | Get current settings |
| `PATCH` | `/api/settings` | Update settings |

### Integrations

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/integrations` | List integrations and status |
| `POST` | `/api/integrations/:id/test` | Test an integration connection |

### Sessions & Activity

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/sessions` | List recent agent sessions |
| `GET` | `/api/metrics` | Usage and cost metrics |

### Cost & Billing

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/companies/:companyId/costs/trend` | Daily cost per agent. `?days=30` (1–90) |
| `GET` | `/api/companies/:companyId/costs/summary` | Total spend vs budget for a date range |
| `GET` | `/api/companies/:companyId/costs/by-agent` | Spend, tokens, and run count per agent |
| `GET` | `/api/companies/:companyId/costs/by-agent-model` | Spend broken down by agent + model |
| `GET` | `/api/companies/:companyId/costs/by-provider` | Spend grouped by provider and model |
| `GET` | `/api/companies/:companyId/costs/by-project` | Spend grouped by project |
| `GET` | `/api/companies/:companyId/costs/window-spend` | Spend in 5h, 24h, and 7d rolling windows |
| `GET` | `/api/companies/:companyId/costs/efficiency` | Per-agent efficiency report (cache hit rate, tokens/run, model suggestions) |
| `POST` | `/api/companies/:companyId/cost-events` | Record a cost event (used internally by adapters) |

All cost endpoints accept optional `?from=ISO_DATE&to=ISO_DATE` query parameters to filter by date range.

**Dashboard proxy** — the dashboard exposes a convenience proxy at `/api/costs?endpoint=ENDPOINT_NAME` that auto-resolves the companyId. Example: `GET /api/costs?endpoint=trend&days=60`.
